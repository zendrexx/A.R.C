LOCAL AI · DEVELOPMENT CONTINUITY

A.R.C.

Agent Recall & Continuity. A local memory that helps a developer resume work with inspectable evidence.

THE PROBLEM

A new session loses the story behind the code.

What changed?

Git shows files and commits, but the developer still has to reconstruct the task.

Why?

Decisions, failed attempts, and useful errors can disappear between sessions.

Is it done?

A claim can sound complete even when tests have not passed at the current Git state.

THE WORKING SYSTEM

Record facts. Retrieve context. Check evidence.

Git + explicit notes + tests→Local SQLite→Local all-minilm→Dashboard + MCP

Source IDs lead back to recorded events. The current Git fingerprint decides whether a passing test still counts.
